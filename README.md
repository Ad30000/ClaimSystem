## Overview of the Project
 The goal of this web-based.NET application is to make it easier for Independent Contractor (IC) lecturers to submit and have their monthly claims approved.  With automated computations and workflow approvals, this system offers a safe, role-based platform for managing claims.
 
The whole point of this part 3 was to intergate a HR that can do many thing like manage the users, create user and set the houly rates which was automated. Add more security was also a big part in the part 3 assignment.

In the system there are about 4 roles which are the Lecturer, Programme Coordinator, Acadmic Manager and Human Resource.
